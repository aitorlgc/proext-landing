# ProExt - Landing Page

Este es un prototipo de landing page moderno para ProExt, una empresa que ofrece toldos, pérgolas bioclimáticas, ventanas y soluciones exteriores premium.

- Incluye secciones: Inicio/hero, Quienes Somos, Dónde Encontrarnos, Catálogo de Productos, Redes Sociales y Contacto.
- Tecnologías utilizadas: HTML, CSS, React (via Babel en el navegador para demo), y Node/Express para un endpoint de contacto.
- Cómo correr localmente:
  1. Asegúrate de tener Node.js instalado.
  2. Instala dependencias (solo si quieres ejecutar el servidor):
     npm install
  3. Ejecuta el servidor: npm start
  4. Abre http://localhost:3000 en tu navegador.

Notas:
- Este proyecto es un prototipo para validar diseño y flujo. En producción, sustituye el React/Babel en navegador por un bundler real (Vite, Webpack) y añade autenticación/validaciones server-side robustas.
- El texto de la sección Quienes Somos es inventado para facilitar la demo; cámbialo al cliente cuando lo revises.
